# Postun — открытый MCP-сервер для Telegram: подключите свой Telegram к ChatGPT, Claude и Claude Code, только чтение

[English](README.md) · **Русский** · [Español](README.es.md) · [Português](README.pt.md) · [Deutsch](README.de.md)

*Каноническая версия — английский [README.md](README.md); переводы следуют за ним и могут отставать.*

**Postun Beta** — открытый MCP-сервер для Telegram (Model Context Protocol, [MCP](https://modelcontextprotocol.io)) в режиме «только чтение». Он подключает ваш собственный аккаунт Telegram к ChatGPT, Claude, Claude Code и другим MCP-клиентам, чтобы нейросеть могла читать ваши чаты, искать сообщения и смотреть публичные каналы. Вы сами выбираете, какие аккаунты и какие права на чтение получит каждый ИИ-клиент, и можете отозвать доступ в любой момент. Поиск сообщений, публичные каналы и файлы реализованы, но пока не проверены на production (см. [статус беты](#статус-беты)).

- Сайт: https://postun.org (English, Русский, Español, Português, Deutsch)
- Кабинет: https://app.postun.org
- MCP-адрес: `https://mcp.postun.org/mcp`
- Репозиторий: https://github.com/AiReformator/postun
- Статус: **бесплатная бета**, экспериментальный проект. Независимого аудита безопасности не было.

## Что это и для кого

Postun — коннектор между **пользовательским аккаунтом** Telegram (не ботом) и ИИ-клиентом, который понимает MCP. После подключения аккаунта ИИ-клиент может вызывать небольшой набор инструментов только для чтения: смотреть список диалогов, читать историю сообщений, искать сообщения, просматривать публичные каналы и получать метаданные или содержимое файлов.

Подходит тем, кто хочет использовать ИИ для Telegram со своими данными:

- получить сводку группового чата или длинной переписки, которую вы пропустили;
- найти нужное в истории чата по смыслу, а не только по ключевому слову;
- проанализировать публичные каналы, на которые вы подписаны;
- подтянуть контекст из Telegram в сессию ChatGPT, Claude или Claude Code.

Чем Postun **не является**:

- Это не бот Telegram и не «нейросеть-бот внутри Telegram». В ваши чаты ничего не добавляется, от вашего имени никто не пишет.
- Это не способ отправлять, удалять или изменять что-либо в Telegram. Прав на запись не существует.
- Это не zero-knowledge. См. раздел [Модель безопасности и приватности](#модель-безопасности-и-приватности).

## Как это работает

```text
Вход через Telegram ──> QR-подключение ──> OAuth-доступ ──> MCP-инструменты
(OIDC, кабинет)         (MTProto,          (вы выбираете     (вызовы только на чтение
                         пароль 2FA —       аккаунты и        из ChatGPT / Claude /
                         по желанию)        права чтения)     Claude Code)
```

1. **Войдите** в кабинет https://app.postun.org через Telegram.
2. **Подключите аккаунт**, отсканировав QR-код в приложении Telegram (вход по MTProto). Если включён облачный пароль (2FA), вы вводите его в кабинете при подключении.
3. **Подключите ИИ-клиент.** Клиент запускает OAuth (с PKCE) на сервере авторизации Postun. На экране согласия вы выбираете, какие подключённые аккаунты и какие права (аккаунты, диалоги, история и поиск, публичные каналы, файлы) доступны этому клиенту.
4. **ИИ-клиент вызывает MCP-инструменты** по адресу `https://mcp.postun.org/mcp` со своим токеном доступа. Каждый вызов проверяется по выданному доступу, затем читается Telegram, и результат возвращается клиенту.

Отозвать доступ клиента или отключить аккаунт можно в кабинете в любой момент.

## Быстрый старт (для пользователей)

1. Откройте https://postun.org и перейдите в кабинет https://app.postun.org. Войдите через Telegram.
2. Подключите аккаунт Telegram по QR-коду.
3. Подключите ИИ-клиент, указав MCP-адрес:

```text
https://mcp.postun.org/mcp
```

**ChatGPT** (пользовательский коннектор, режим разработчика): включите режим разработчика в настройках ChatGPT, добавьте собственный MCP-коннектор, вставьте адрес выше и пройдите экран согласия OAuth. Названия пунктов меню зависят от тарифа и версии ChatGPT.

**Claude Code:**

```bash
claude mcp add --scope user --transport http postun https://mcp.postun.org/mcp
```

Затем выполните `/mcp` внутри Claude Code и авторизуйте `postun`. Важно: работа Claude Code на production **ещё не проверена** (см. [таблицу статуса](#статус-беты)).

**Другие MCP-клиенты** с поддержкой удалённых HTTP MCP-серверов и OAuth могут использовать тот же адрес.

Совет для беты: сначала попробуйте на тестовом аккаунте или нечувствительных чатах.

## MCP-инструменты

Все инструменты работают **только на чтение**. Нет инструмента, который что-то отправляет, меняет или удаляет, и нет права записи. Сервер проверяет право для каждого инструмента независимо от подсказок клиента.

| Инструмент | Что делает | Право |
|---|---|---|
| `list_accounts` | Список аккаунтов Telegram, разрешённых этому клиенту | `accounts:read` |
| `list_dialogs` | Список чатов, групп и каналов (диалогов) | `dialogs:read` |
| `get_history` | Чтение истории сообщений диалога | `messages:read` |
| `search_messages` | Поиск сообщений | `messages:read` |
| `search_channels` | Поиск публичных каналов | `channels:read` |
| `get_channel_posts` | Чтение постов публичного канала | `channels:read` |
| `get_media_info` | Метаданные файла или медиа | `media:read` |
| `get_media` | Передача файла или медиа ИИ-клиенту | `media:read` |

## Модель безопасности и приватности

- **Шифрование при хранении.** Сессии Telegram шифруются AES-256-GCM. У каждого аккаунта свой ключ, обёрнутый ключом шифрования ключей (KEK), который хранится как секрет Cloudflare.
- **Нет логов переписки и запросов.** Журналы Cloudflare отключены, а код может писать в консоль только константные строки. Это проверяется в CI (`npm run check:logging` и проверка конфигурации логов Cloudflare).
- **Нет архива.** Содержимое сообщений и файлов существует только в оперативной памяти на время передачи ИИ-клиенту. Сохраняются зашифрованные сессии Telegram, выданные доступы (разрешения), дневные счётчики и ограниченные служебные данные.
- **Только чтение по построению.** Существуют только права на чтение: `accounts:read`, `dialogs:read`, `messages:read`, `channels:read`, `media:read`.
- **Отзыв в любой момент.** Отзовите клиента или отключите аккаунт в кабинете.
- **Открытый код.** Код шифрования, проверок доступа и правила «без логов» публичен (см. следующий раздел).

**Чем это не является.** Postun — **не zero-knowledge**. Оператор и инфраструктура (Cloudflare Workers и Durable Objects) входят в модель доверия: чтобы обратиться к Telegram, сервис расшифровывает вашу сессию, и недобросовестный или скомпрометированный оператор, контролирующий развёртывание и его секреты, технически мог бы получить доступ к данным. ИИ-провайдер, которого вы подключаете (OpenAI, Anthropic и др.), получает то, что возвращают инструменты, и хранит это по своим правилам. Сначала используйте тестовый аккаунт и решите, чем готовы делиться.

Подробнее: [docs/03_SECURITY_PRIVACY.md](docs/03_SECURITY_PRIVACY.md).

## Философия: открытость по замыслу (принцип Керкгоффса)

Код полностью открыт, чтобы каждый мог проверить, как на самом деле работают шифрование, проверки доступа и правило «без логов». Согласно [принципу Керкгоффса](https://ru.wikipedia.org/wiki/Принцип_Керкгоффса), безопасность должна опираться только на секретность ключей, а не на сокрытие устройства системы. Настоящие ключи лежат в секретах Cloudflare и никогда не попадают в этот репозиторий; закрыты только ключи, токены, данные пользователей, конфигурация доступа нашего развёртывания и материалы закрытых инцидентов безопасности. Если вы не хотите доверять нашему развёртыванию, прочитайте код и запустите свой экземпляр (см. «Самостоятельная установка»).

## Разработка

Postun работает на Cloudflare Workers, Durable Objects (на SQLite), D1 и Workers KV и написан на TypeScript. Node.js 26 (`.nvmrc`), npm workspaces, один lockfile.

```bash
source ~/.nvm/nvm.sh && nvm use   # Node 26
npm ci
npm run lint
npm run typecheck
npm test
npm run build
npm run check:secrets
npm run check:logging
```

`npm run ci` запускает всю цепочку. Тесты используют синтетические данные и локальный Workers runtime (Miniflare/workerd); реальные Telegram, IDP и Cloudflare-ресурсы в CI не используются. Настоящие секреты задаются только через `wrangler secret put` в своём аккаунте Cloudflare; примеры переменных — в `apps/*/.dev.vars.example` и `templates/.env.example`.

Структура репозитория:

```text
apps/web/            Cloudflare Workers (статические файлы): beta-лендинг, документы, кабинет (статический)
apps/auth/           postun-auth: Telegram OIDC, web-сессия, MCP OAuth (authorization server), API кабинета
apps/mcp/            postun-mcp: MCP resource server, SessionAndQuotaDO, Telegram (mtcute) adapter
apps/admin/          postun-admin: IDP OIDC BFF, агрегаты, suspend/resume
packages/contracts/  общие схемы, scopes, шифрование envelope, курсоры, RPC-контракты
migrations/control/  D1 postun-control (только auth)
migrations/admin/    D1 postun-admin-meta (только admin)
```

Правила для участников: [CONTRIBUTING.md](CONTRIBUTING.md). В тестах и issues используйте синтетические данные; не прикладывайте настоящие учётные данные, коды входа, личные чаты и файлы.

## FAQ

**Что такое MCP-сервер для Telegram?**
MCP (Model Context Protocol) — открытый стандарт, позволяющий ИИ-клиентам, таким как ChatGPT, Claude и Claude Code, вызывать внешние инструменты. MCP-сервер для Telegram предоставляет данные Telegram в виде таких инструментов. Postun — размещённый (hosted) сервер только для чтения, работающий с вашим собственным аккаунтом Telegram.

**Postun — это бот Telegram?**
Нет. Бот живёт внутри Telegram, и вы с ним переписываетесь. Postun ничего не добавляет в Telegram: он использует вход вашего пользовательского аккаунта и даёт вашему ИИ-клиенту инструменты только для чтения. Если вы ищете «ChatGPT-ботов в Telegram», это другое.

**Как подключить Telegram к ChatGPT или Claude?**
Войдите на https://app.postun.org, подключите аккаунт по QR-коду, затем добавьте `https://mcp.postun.org/mcp` как собственный MCP-коннектор в ChatGPT (режим разработчика) или выполните `claude mcp add --scope user --transport http postun https://mcp.postun.org/mcp` для Claude Code. См. [Быстрый старт](#быстрый-старт-для-пользователей).

**Это безопасно?**
Система спроектирована осторожно: права только на чтение, зашифрованные сессии, нет логов переписки, отзываемый доступ, открытый код. Но это бета без независимого аудита и не zero-knowledge: оператор и инфраструктура Cloudflare входят в модель доверия, а ваш ИИ-провайдер хранит данные по своим правилам. Сначала пробуйте на нечувствительных данных.

**Это бесплатно?**
Да, бета бесплатна, лимит — 10 000 успешных операций в сутки по UTC на владельца. Платежей в бете нет, лимит может измениться.

**Может ли ИИ отправлять сообщения или менять что-то в Telegram?**
Нет. Существуют только инструменты чтения, и сервер принудительно проверяет права на чтение.
